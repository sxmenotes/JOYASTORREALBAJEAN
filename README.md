# Torrealba Joyas - Landing Page

Landing page para la marca de joyería fina Torrealba Joyas.

## Estructura del Proyecto

```
/
├── index.html        # Estructura de la landing page con Tailwind CSS via CDN
├── README.md         # Documentación del proyecto
├── LICENSE           # Licencia
├── /css
│   └── styles.css    # Animaciones y estilos personalizados
├── /js
│   └── main.js       # Interactividad (Scroll suave, animaciones on-scroll)
└── /assets           # Recursos visuales (imágenes, logos)
```

## Tecnologías Utilizadas
- **HTML5**: Estructura semántica.
- **Tailwind CSS**: A través de CDN y configuración embebida para rápido desarrollo de la UI y diseño responsive.
- **Vanilla CSS**: Para control específico de animaciones de scroll y *keyframe animations*.
- **Vanilla JavaScript**: Lógica de menú móvil y *Scroll Reveal* con IntersectionObserver.

## Instrucciones de uso local
1. Clona o descarga este repositorio/carpeta.
2. Abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Safari, Firefox). No se requiere servidor local ya que no hay llamadas a APIs externas ni módulos que restrinja CORS.
3. El diseño es 100% responsive, adaptándose desde teléfonos móviles hasta monitores ultra anchos.

## Paleta de Colores Oficial
- **Blanco** (`#FFFFFF`): Base y fondos principales.
- **Negro** (`#111111`): Tipografía, pies de página, contraste estructural.
- **Plateado** (`#C0C0C0`): Acentos, líneas divisorias.
- **Dorado** (`#D4AF37`): Botones, estado hover, puntos de interés principal.
